# АгроМаркет — запуск проекта в VS Code

Это учебный интернет-магазин на React + Vite. Данные товаров загружаются из `db.json` через `json-server`.

## Что есть в проекте
- Главная страница и каталог товаров.
- Компонент `ProductCard.jsx`, который получает товар через `props`.
- Загрузка через `fetch()` и состояние загрузки/ошибки.
- Поиск, фильтр по категориям и сортировка.
- Корзина с изменением количества и автоматическим подсчётом суммы.
- Страница товара, оформление заказа, демонстрационные формы входа/регистрации.
- Переключение русского и казахского языка.
- Адаптация под мобильные телефоны и средние CSS-анимации.
- Демонстрационные товары находятся в `db.json`.

## Что нужно установить
Установи Node.js LTS с официального сайта: https://nodejs.org/
Затем открой VS Code.

## Запуск
1. Распакуй `AgroMarket_VSCode.zip`.
2. В VS Code выбери **File → Open Folder** и открой папку `AgroMarket`.
3. Открой терминал: **Terminal → New Terminal**.
4. Выполни команду:

```bash
npm install
```

5. Запусти API с товарами в первом терминале:

```bash
npm run server
```

Оставь этот терминал открытым. Адрес API: http://localhost:3001/products

6. Открой второй терминал кнопкой `+` в панели терминала и запусти сайт:

```bash
npm run dev
```

7. Открой адрес, который покажет Vite, обычно http://localhost:5173

Важно: для работы каталога должны одновременно работать обе команды — `npm run server` и `npm run dev`.

## Проверка
- На главной странице должны появиться популярные товары.
- Открой каталог и попробуй поиск, категории и сортировку.
- Нажми «В корзину» и открой корзину в шапке.
- Измени количество товара и проверь итоговую сумму.
- Нажми `РУС` / `ҚАЗ`, чтобы переключить язык.
- Попробуй открыть страницу товара, оформить демонстрационный заказ и открыть форму входа.

## Как устроены основные файлы
- `src/App.jsx` — основная логика и страницы.
- `src/components/ProductCard.jsx` — отдельная карточка товара.
- `src/translations.js` — тексты на русском и казахском.
- `src/index.css` — внешний вид и адаптивность.
- `db.json` — товары для json-server.
- `package.json` — команды и зависимости.

## Полезные команды
```bash
npm run build
```
Проверяет, собирается ли проект для публикации.

## Важно
Форма входа/регистрации демонстрационная: настоящие аккаунты не создаются, пароли не сохраняются. Оформление заказа тоже учебное — реальные платежи и доставка не подключены. Фотографии загружаются из интернета, поэтому для них нужен интернет.
